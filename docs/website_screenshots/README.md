# Screenshots Directory

This folder contains AWS console screenshots for documentation.

See [SCREENSHOTS.md](../SCREENSHOTS.md) for the complete list of recommended screenshots.

## Directory Structure

```
screenshots/
├── architecture/     # Architecture diagrams
├── vpc/              # VPC, subnets, route tables, endpoints
├── ecs/              # Cluster, service, tasks
├── api-gateway/      # API, routes, VPC Link
├── dynamodb/         # Table, items
├── cloudfront/       # Distribution, origins
├── s3/               # Buckets, policies
├── ecr/              # Repository, images
├── iam/              # OIDC provider, roles
├── cloudwatch/       # Logs, insights, dashboards
└── cicd/             # GitHub Actions workflows
```

## Quick Tips

1. Use PNG format for clarity
2. ~1200px width recommended
3. Blur AWS Account ID in screenshots
4. Use light mode for consistency
